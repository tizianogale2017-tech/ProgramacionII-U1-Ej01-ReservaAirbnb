# ReservaAirbnb

Programación II - Unidad 1 - Ejercicio 1

## Consigna
Modelar una reserva de alojamiento temporal, calculando el costo total
de la estadía según noches y precio por noche.

## Lógica
La clase encapsula tres atributos privados (`nombreHuesped`, `noches`,
`precioNoche`). El constructor valida que `noches` y `precioNoche` sean
mayores a cero antes de asignarlos, lanzando `IllegalArgumentException`
si no se cumple. `calcularTotal()` retorna el producto de ambos valores.
`mostrarDetalle()` imprime por consola toda la información de la
reserva, incluyendo el total calculado.
